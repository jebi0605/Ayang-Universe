# Ayang-Universe
Website of a fictitious company called Ayang Universe
# Ayang Universe 홈페이지

Ayang Universe는 모닝똥 연구를 통해 인류의 삶을 혁신하는 독창적인 기업입니다. **본 문서는 허구의 기업 Ayang Universe의 가상 홈페이지 프로젝트를 설명합니다.**

## 프로젝트 소개

이 홈페이지는 Ayang Universe의 혁신적인 기술력, 지속적인 성장 가능성, 그리고 독특하고 흥미로운 제품 라인을 소개하는 데 중점을 두고 있습니다. 뤼튼 테크놀로지스 스타일의 세련됨과 우주/신비로운 느낌의 역동적이고 화려한 비주얼 효과를 결합하여 방문자에게 강한 인상을 남기도록 디자인되었습니다.

-   **기술 스택:** HTML5, CSS3, JavaScript (Particles.js 라이브러리 포함)
-   **코드 구조:** 파일 개수 최소화 요청에 따라 모든 HTML, CSS, JavaScript 코드가 `index.html` 파일 하나에 통합되어 있습니다. 가독성 향상을 위해 줄바꿈 및 들여쓰기가 충분히 적용되었으며, 설명 주석은 최소화되었습니다.
-   **로고:** 프로젝트 루트 디렉토리에 `logo.png` 파일이 필요합니다.

## 주요 특징

-   **역동적인 배경:** Particles.js를 활용하여 우주와 같은 느낌의 파티클 애니메이션 배경 구현
-   **동적인 스크롤 애니메이션:** 페이지 스크롤 시 각 주요 섹션(기술력, 성장, 제품, FAQ, 개인정보 처리 방침)이 뷰포트에 들어오고 나갈 때마다 페이드 인 및 이동 효과가 반복 적용됩니다.
-   **시각적 효과 강화:** 모든 기술, 성장, 제품 아이템 박스에 마우스 호버 시 빛나고 약간 확대되는 화려한 애니메이션 효과 추가. 마지막 총평 문단에는 박스 스타일 대신 일반 문단 스타일 적용.
-   **박스 레이아웃:** 기술, 성장, 제품 아이템들을 그리드 레이아웃을 사용하여 1:1에 가까운 비율의 개별 박스 형태로 시각화했으며, 반응형을 지원합니다.
-   **풍성한 내용:** Ayang Universe의 기술력, 성장 비전, 제품 라인에 대한 상세하고 알찬 설명 포함. 연 매출(-1.972원) 정보 명시 포함.
-   **FAQ 및 개인정보 처리 방침 섹션 추가:** 사용자에게 필요한 정보를 제공하기 위한 섹션 포함. 실제 내용은 회사의 정보로 대체해야 합니다.
-   **(주) 회사명 명시:** 푸터 하단에 회사의 정식 명칭을 명시했습니다.
-   **반응형 디자인:** 다양한 기기(데스크톱, 모바일, 태블릿 등)에서 최적의 보기 경험을 제공하는 반응형 웹사이트입니다.
-   **부드러운 스크롤:** 네비게이션 클릭 시 해당 섹션으로 부드럽게 이동하는 기능이 포함되어 있습니다.

## 시작하기

1.  이 프로젝트 코드 (`index.html`)를 로컬 컴퓨터에 다운로드합니다.
2.  `index.html` 파일이 있는 같은 폴더에 회사의 로고 이미지 파일인 `logo.png`를 저장합니다.
3.  `index.html` 파일을 웹 브라우저로 열거나, 로컬 웹 서버를 실행하여 홈페이지를 확인합니다.

## GitHub Pages로 배포하기 (무료 호스팅)

GitHub Pages를 이용하면 무료로 이 홈페이지를 온라인에 게시할 수 있습니다.

1.  GitHub 계정이 없다면 [GitHub](https://github.github.com/signup?ref_cta=Sign+up&ref_loc=header+logged+out&ref_page=%2F&source=header-banner)에 가입합니다.
2.  새 저장소(Repository)를 생성합니다. 저장소 이름은 자유롭게 정할 수 있습니다.
3.  로컬에 저장한 `index.html` 파일과 `logo.png` 파일을 이 새 저장소에 업로드합니다. (Git 명령어를 사용하거나 GitHub 웹사이트에서 직접 업로드할 수 있습니다.)
4.  저장소 페이지에서 'Settings'(설정) 탭을 클릭합니다.
5.  왼쪽 메뉴에서 'Pages'를 클릭합니다.
6.  'Source' 섹션에서 'Deploy from a branch'를 선택합니다.
7.  'Branch' 드롭다운에서 홈페이지 파일이 있는 브랜치(일반적으로 `main` 또는 `master`)를 선택하고, 폴더는 `/(root)`를 선택합니다.
8.  'Save'(저장) 버튼을 클릭합니다.
9.  GitHub Pages가 활성화되는 데 시간이 다소 소요될 수 있습니다 (보통 몇 분, 최대 10~20분). 페이지 상단에 표시되는 GitHub Pages 주소(`https://[사용자이름].github.io/[저장소이름]/` 형태)로 접속하여 홈페이지를 확인할 수 있습니다.

## 참고 사항

-   모든 코드가 하나의 파일에 있어 파일 관리는 간단하지만, particles.js 라이브러리 코드 자체의 길이 때문에 전체 코드의 줄 수가 많아 보일 수 있습니다.
-   회사의 연 매출(-1.972원)은 성장 섹션에 명시되었습니다.
-   제품 소개 내용은 제공된 설명을 바탕으로 상세하게 작성되었습니다. 필요에 따라 더 자세한 정보나 이미지를 추가할 수 있습니다.
-   FAQ 및 개인정보 처리 방침 섹션의 내용은 예시입니다. 실제 회사의 정보로 내용을 변경해야 합니다.
